## １．データについて
### 統計表名：
大学・短期大学・高等専門学校及び専修学校卒業予定者の就職内定状況等調査 表題：大学　文理別就職内定率
### データセット名または表番号：
政府統計コード「00400402」
### データ取得日：
2026/01/26
### 各列の意味：
- 各列の並びは「"表章項目","時間軸(12月)","学校区分","/学部（文系・理系）","全体","文系","理系"」
    - 表章項目＝何の数値か(就職内定率(%)・就職内定率_前年度同期増減値)
    - 時間軸(12月)＝年、学校区分＝学校分け(全体・うち国公立のみ・うち私立のみ)
    - /学部（文系・理系）＝nanによりなし
    - "全体","文系","理系"＝学部ごとの区別(全体・文系・理系)
### 単位と注意点：
内定率は%ですが、内定率の増減値は%ではなく数値になります

## ２．未使用UIについて
### 使用したUI部品名：
- コンテンツの折り畳み(.extender)
- 要素(グラフ概要)の列挙(.columns)
- トグルスイッチ(.toggle)
### UIを使った目的：
- extender…アプリの使用方法の説明の際に文章量が多くなるため
- columns…グラフの簡単な概要を表示する場所を取るため
- toggle…表示の状態を一目でわかるようにするため
### アプリのどこで使っているか：
- extender…タイトルの下,使用方法について
- columns…ページ下部,散布図の下の表示
- toggle…サイドバー上部の詳細表示の切り替え
